# Deskripsi Proyek
Web statis ini dibuat untuk menampilkan galeri dan informasi sebuah studio foto.
Di dalamnya terdapat beberapa halaman utama, yaitu halaman beranda, tentang, layanan,
galeri, dan kontak. Proyek ini bertujuan untuk menyajikan portofolio studio foto dengan
tampilan yang informatif dan menarik.

# Transparansi Penggunaan AI
Dalam proses pengerjaan web ini,saya menggunakan AI sebagai asisten teknis:

Gemini: Saya gunakan untuk membantu menyusun struktur kode, memberikan
saran saat penulisan kode, serta membantu memperbaiki error atau kendala 
selama proses coding.

ChatGPT: Saya gunakan untuk mencari referensi dan rekomendasi desain. Namun,
saya tidak menggunakan desain tersebut secara mentah-mentah, saya melakukan modifikasi
dan penyesuaian lagi pada tampilan akhirnya agar sesuai dengan keinginan saya sendiri.
